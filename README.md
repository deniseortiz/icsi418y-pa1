## Description
This page lets users add tasks and choose a Low, Medium, or High priority. Users can also mark tasks as completed or delete them.

## Installation

1. Download the repository.
3. Keep index.html, style.css, and script.js together.
4. Open index.html in your browser.
5. Start testing features by adding and removing tasks in index.html page.

## Usage
Open index.html in a web browser. Enter your task, select the priority level, and click the "Add Task" button. Once completed, click the "Complete" button which will cross out the task, or you also have the option to press the "Delete" button to remove the task entirely. All tasks will be refreshed and disappear when the page is refreshed.
